# 宝宝用品小柜

宝宝用品小柜是一个家庭共用的微信小程序。家人可以一起记录纸尿裤、奶粉等用品的存量和用量，查看哪些快用完、哪些快过期。

## 日常使用

1. 在「家庭」创建家庭，通过微信邀请家人加入。
2. 在「用品」添加用品。先选纸尿裤、奶粉等内置类型，再点选推荐规格和单位，列表末尾可以自己填写。
3. 用「整理现有物品」录入实际余量，用「新购入库」登记新买的用品。可以逐项选择，也可以粘贴文字清单后核对。每包数量、开封期限和有效期按实际包装填写。
4. 日常点击「记使用」。纸尿裤等按数量记录，奶粉等可分别记开封和用完。实物与账面有差异时可以盘点，过期或损坏的用品可以登记报损。
5. 在首页查看低库存、快用完和临期提醒。「查看趋势」默认展示消耗。同一天的用量合计，跨天补记保留区间总量。库存变化和采购入库可以切换查看。

## 本地启动

准备微信开发者工具、微信小程序 AppID 和可用的微信云开发环境。本地测试已在 Node.js 24 验证。

1. 将 `code/config.example.js` 复制为 `code/config.js`，填入自己的云环境 ID `envId`。
2. 将 `code/project.config.example.json` 复制为 `code/project.config.json`，替换其中的 `appid`。在微信开发者工具中导入 `code/` 目录。
3. 在云开发数据库创建 `baby_families`、`baby_routes` 和 `baby_invites` 集合，禁止客户端直接读写。
4. 在微信开发者工具里将 `code/cloudfunctions/api/` 上传并部署到所选云环境，选择云端安装依赖。部署后编译小程序，在「家庭」创建家庭即可开始录入。

应用内提醒可随库存记录查看。需要微信订阅通知时，在本地配置 `reminderTemplateId`，并为云函数配置对应的 `SUBSCRIBE_TEMPLATE_ID`、模板字段和定时触发器。部署与权限细节见 [云函数 API](code/docs/api.md#部署)。

## 开发与测试

在仓库根目录运行以下命令。测试使用 Node.js 自带的测试框架，无需连接云环境。

```sh
npm --prefix code test
```

- [页面](code/pages/)和[组件](code/components/)使用原生 WXML、WXSS 和 JavaScript。
- [云函数](code/cloudfunctions/api/)处理身份、家庭权限、库存和流水。
- [测试](code/tests/)覆盖库存、历史补记、回归场景及页面交互。

当前版本适用于一个家庭管理一个宝宝的用品。真机登录、微信分享、云端并发及订阅通知需在实际小程序环境验证。详见[业务需求](code/docs/specs/2026-11-19-baby-supplies-feature-spec.md)与[验收记录](code/docs/verification.md)。
