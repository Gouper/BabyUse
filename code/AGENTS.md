# 宝宝用品小柜

## 项目简介

微信原生小程序，供家庭成员共享宝宝用品库存，支持批次与有效期、购买入库、使用记录、盘点、报损、提醒及趋势。首版一个家庭管理一个宝宝，不包含商城、支付或医疗建议。

## 目录

- `app.js / app.json / app.wxss`：入口、页面注册与全局样式。
- `pages/`：首页、用品、记录、家庭、详情、编辑、入库和趋势页面。
- `utils/api.js`：客户端统一云函数调用入口。
- `config.js`：云环境 ID 与微信订阅模板配置。
- `cloudfunctions/api/`：云函数入口、业务规则和部署配置。
- `tests/`：领域规则、云函数适配和页面模板检查。
- `docs/specs/2026-11-19-baby-supplies-feature-spec.md`：业务需求基线。
- `docs/api.md`：接口、部署步骤与计算规则。
- `docs/verification.md`：验收记录与已知限制。

## 开发约定

- 使用原生 WXML、WXSS 和 JavaScript，产品名称统一为“宝宝用品小柜”。
- 延续现有雾紫色界面，文案使用简洁中文，注意手机布局与长名称换行。
- 客户端通过 `api` 云函数访问业务数据；身份取自服务端微信上下文，家庭隔离及角色权限必须在服务端校验。
- 库存变更和流水保持事务一致，写操作处理重复请求。购买、期初、使用、报损和盘点分别统计。
- 补记、修改及撤销不得重复扣减盘点已覆盖的消耗。开封与用完分开记录，过期库存排除可用量但保留待处理记录。
- WXML 表达式使用 `{{ ... }}`；逻辑运算符直接写 `&&`，不要写成 `&amp;&amp;`。
- 不使用模拟数据冒充真实家庭库存，不擅自变更云环境或开通付费资源。

## 验证与运行

- 在本目录执行 `npm test`；修改 JavaScript 后执行相应文件的 `node --check`。
- 修改 WXML 后，使用微信开发者工具编译验证；模板静态测试不能替代真实编译。
- 微信开发者工具打开本目录，云函数目录为 `cloudfunctions/`，部署函数名为 `api`，需云端安装依赖。
- 数据库集合为 `baby_families`、`baby_routes`、`baby_invites`，客户端权限均为不可读写。
- 真实登录、邀请分享、双成员并发、订阅消息和定时触发需在实际云环境验证；交付时明确区分本地测试与真实环境验收。
