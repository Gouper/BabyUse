# 宝宝用品首版实施计划

执行授权：用户于 2026-11-19 明确要求按特性文档开发，覆盖 Spec 中早期的待授权说明。

目标：微信原生小程序，家庭共享用品、批次库存、使用流水、提醒与趋势。
架构：客户端仅调用统一云函数，服务端从微信上下文取身份，在数据库事务内校验家庭成员和角色、更新库存及流水。纯业务模块接受可注入时钟和身份用于自动化测试。云环境、模板和费用不做假设。
技术：原生 WXML/WXSS/JavaScript、wx-server-sdk、Node 内置测试。
Spec：../specs/2026-11-19-baby-supplies-feature-spec.md

## 必守约束

家庭隔离由服务端执行；不信任客户端操作者。购买、期初、消耗、报损、盘点独立统计。开封转状态，用完计消耗；过期只排除可用数。批量导入必须预览确认、幂等且提示潜在重复。漏记不填零，不提供医疗建议。

## 复核重点

跨家庭伪造 ID；并发重试；同日盘点与跨日补记；撤销后不能重扣盘点前消耗；未知单位日期和空值；通知定时入口不可由客户端伪造触发。
