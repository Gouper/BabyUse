# 宝宝用品小柜界面改版

日期：2026-11-19。用户授权使用frontend-design优化现有界面。

## 设计方向

宝宝用品收纳手账。以轻盈、易扫读、可单手操作为目标。浅雾紫 #F6F5FA 为页面底，白色内容区，紫色 #7561CF 为主操作，深灰紫 #302D43 为正文，柔黄 #F5CB70 与珊瑚色 #E89983 区分提醒。系统中文字体，使用32/44rpx标题、28rpx正文、24rpx辅助信息，数字单独突出。左对齐为主，空状态居中。

## 版式

首页为宝宝与库存概览、四类提醒、小型快捷入口、待处理列表。用品为搜索与操作栏、用品列表，名称与规格左对齐，余量右对齐。详情为余量主区、操作区、批次及容器列表。编辑与入库按相关字段分组，保留说明和确认。记录采用中文类型与时间线。家庭页区分成员、邀请、订阅、退出。趋势突出图和日期筛选。

相比原界面，不采用整页青色与同等大小按钮；相比插画重度方案，不引入远程图片或字体。个性集中于轻柔色彩和用品收纳的几何图形，数据及操作区保持安静。

## 实施与验证

1. 重做共享样式和8页模板，保留业务函数、权限、请求及真实数据来源。
2. 必要展示数据在页面JS推导，不变更库存及后端逻辑。
3. 用微信真实wcc编译所有WXML；运行npm test及JS语法检查。
4. 独立复核交互入口、可读性、溢出、空态、错误态。开发者工具当前最小化，工具无法恢复，真实模拟器视觉检查若仍不可用需披露。
