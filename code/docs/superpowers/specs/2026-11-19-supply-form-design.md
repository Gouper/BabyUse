# 用品选择与模板

新增用品从用品类型开始。内置模板使相关规格、分类、单位和规则优先可选，各自由填写项保留末尾的「其他，自己填写」。可选自定义用品从空表单开始。切换模板时更新预设值，保留手工填写的内容，提示核对单位相关的包装换算。实物包装决定包内数量和开封期限。

完整自动填表可以减少点击，但规格、包装和期限随实物变化。采用相关选项优先和少量可修改默认值。使用方式和有效期继续使用现有枚举，存量用品保持现有编辑约束。

提醒设置默认折叠，按有效期规则展示适用项。报损和盘点原因提供常用选项和自定义。入库和记使用共用可按名称、规格搜索的用品列表。入库可就地新增用品，成功返回后选中该用品并保留当前日期与其他行。单独新增后可直接去新购入库或录现有库存。
