# 家庭退出与找回

最后一位成员可以确认退出。家庭暂停使用，原库存及历史保留 72 小时。原微信账号可以在家庭页查看截止时间并找回家庭，恢复管理员身份和历史资料。已有家庭时需先退出当前家庭。旧邀请在退出时失效，恢复后可重新发出邀请。

## 方案

采用原微信账号找回，云函数使用微信调用上下文识别账号。找回码需要用户另行保管凭证，因此采用现有微信身份。保留家庭原文档，用服务端字段记录可找回的账号和截止时间。

## 边界

退出和找回均在事务内校验身份及家庭状态。退出确认绑定到所显示的家庭，期间若有人加入则停止关闭。72 小时到期时立即拒绝找回，由独立于订阅提醒的每小时定时任务清理云端数据。
