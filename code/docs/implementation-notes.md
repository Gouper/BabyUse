# 实施决定与运行边界

2026-11-19 用户明确要求依本 Spec 开发，早期 Spec 的“待授权”仅描述编写当时状态。

## 架构

保留微信原生项目；客户端经 `api` 云函数读写，微信 OPENID 来自可信服务端上下文。数据库业务集合应配置为客户端不可读写。首版以家庭为事务聚合，家庭内流水和库存原子更新，适用于小家庭规模。家庭文档累积增长需在接近数据库文档大小限制前迁移为分集合事务模型，不可静默截断历史。

无云环境 ID、模板 ID 或控制台连接，代码可本地测试，不代表已部署。具体配置以 README 和 docs/api.md 为准。

## 待真实环境验证

1. 在既有 CloudBase 环境核实文档数据库和事务能力；不自动创建付费资源。
2. 上传云函数及安装其生产依赖，创建所需集合并关闭客户端直接访问。
3. 两个真实微信账号验证分享邀请、撤销邀请、退出及权限变化。
4. 开发者工具编译及手机验证所有页面、键盘输入、预览确认和错误提示。
5. 核实小程序可用订阅模板和字段，验证真实用户授权与发送状态。
6. 根据云平台定时器时区确认北京时间每日 09:00 实际触发；先进行一次人工观察验证。
7. 两成员同时写入并重试同一请求，核对库存与流水一致。
